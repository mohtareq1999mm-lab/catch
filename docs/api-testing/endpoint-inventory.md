## Shared invariants to verify

- Envelope: every success = `{success:true,message:...,data:...}`; errors = `404 {success:false,message:...,data:null}` shaped; throttling = `{success:false,message:...,data:null}` + `429`.
- `data` of list endpoints = paginated Laravel paginator shape (`data`, `links`, `meta`) — verify actual shapes per resource.
- Empty DB: all list endpoints must return 200 with empty `data` (no 500s).
- No cross-user or cross-channel leaks (guest endpoints; channel/lang middleware only).
- Response sizes reasonable; no stack traces or secrets with `APP_DEBUG=true` (note: APP_DEBUG=true locally — error bodies leak; must check on 5xx).
